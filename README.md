# 🧊 КУБ — месенджер

Власний веб-месенджер з анімованим екраном завантаження (3D-куб, **5 секунд**), чатами, особистими повідомленнями, контактами та профілем.

## ✨ Можливості

- 🧊 **Екран завантаження** — об'ємний обертовий 3D-куб із прогрес-баром (5 с)
- 💬 **Чати** — список чатів із пошуком, непрочитаними та часом останнього повідомлення
- ✉️ **Особисті повідомлення (ЛС)** — бульбашки, роздільники днів, індикатор «друкує…», імітація відповіді співрозмовника, звуки та вібрація при надсиланні
- 👥 **Контакти** — список контактів + створення нового контакту через нижню шторку
- 👤 **Профіль** — аватар, ім'я, нікнейм, біо, статистика; редагування та вибір кольору аватара
- 🔻 **Нижній бар** — навігація «Чати / Контакти / Профіль» з анімованою «пігулкою»
- 🎞 **Анімації** — перетворення куба, плавні переходи екранів, поява повідомлень, пульсація бейджів
- 💾 **Збереження** — усі чати й контакти зберігаються в `localStorage`
- 📱 **PWA** — можна встановити на телефон як застосунок (маніфест + service worker, офлайн-режим)

## 🚀 Запуск

Це статичний сайт — бекенд не потрібен:

```bash
# просто відкрийте index.html у браузері, або:
python3 -m http.server 8080
# і перейдіть на http://localhost:8080
```

## 🗂 Структура

```
├── index.html            # розмітка застосунку + splash із кубом
├── css/style.css         # стилі та всі анімації
├── js/app.js             # логіка (чати, ЛС, контакти, профіль, навігація)
├── assets/icon.png       # іконка застосунку
├── manifest.webmanifest  # PWA-маніфест
└── sw.js                 # service worker (офлайн-кеш)
```

## 🛠 Технології

Чистий HTML + CSS + JS, без залежностей. Працює на телефоні та десктопі.
